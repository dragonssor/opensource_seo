# 가산동 복합 상가 상세주소 미부여 건물 조사

서울 금천구 가산동(법정동코드 `1154510100`)의 복합 상가 중 **상세주소(동·층·호)가 부여되지 않은 건물**을
juso.go.kr 공개 데이터 매칭으로 찾는 도구입니다. Python 3 표준 라이브러리만 사용합니다.

## 1. 데이터 내려받기

| 데이터 | 받는 곳 | 필수 |
|---|---|---|
| 건물DB (서울특별시) | business.juso.go.kr → 주소정보 제공 → 제공하는 주소 → 건물DB | ✅ |
| 상세주소DB (상세주소 표시 / 상세주소 동 표시, 서울) | 같은 메뉴 → 상세주소DB | ✅ |
| 건축물대장 표제부 (금천구) | 건축HUB(hub.go.kr) 건축데이터 개방 또는 공공데이터포털 API(getBrTitleInfo)를 CSV로 저장 | 권장 |

`.zip` 파일은 압축을 풀지 않고 그대로 넣어도 됩니다. 인코딩(cp949/utf-8)은 자동으로 판별합니다.

## 2. 실행

```bash
python3 match_detail_address.py \
  --building 건물DB_서울.zip \
  --detail 상세주소DB_서울.zip 상세주소동DB_서울.zip \
  --register 표제부_금천구.csv \
  --output gasan_no_detail_address.csv
```

옵션:
- `--all`: 상세주소가 *있는* 복합 상가도 함께 출력(비교용)
- `--min-ho`, `--min-floors`: 복합 상가 판정 기준 (기본 호수≥2 또는 지상층≥2)
- `--building-cols`, `--detail-cols`: 레이아웃이 바뀌었을 때 컬럼 위치(1부터) 직접 지정
- `--bjd-code`: 다른 법정동을 조사할 때

## 3. 매칭 방법

1. **건물DB**에서 법정동코드가 가산동인 건물만 추립니다.
2. 모든 데이터셋에 공통으로 들어 있는 **도로명주소 키** `도로명코드(12)|지하여부|건물본번|건물부번`로 건물을 식별합니다.
3. **상세주소DB**에서 키별 상세주소(동·층·호) 건수를 셉니다. 컬럼 위치는 자동으로 탐지합니다.
   도로명코드(12자리) 뒤에 처음 나오는 0/1 컬럼을 지하여부로, 그 뒤의 숫자 컬럼 두 개를 건물 본번·부번으로 봅니다.
4. **복합 상가 판정**
   - 건축물대장이 매칭되면 주용도·기타용도에 근린생활시설·판매시설·업무시설 등이 있고, 호수≥2, 지상층≥2 또는 여러 동 중 하나를 만족하는 건물
   - 대장이 매칭되지 않으면 건물명 키워드(상가·프라자·타워·센터·지식산업 등)로 대신 판정합니다. 결과의 `판정근거` 열에 표시됩니다.
5. 복합 상가이면서 상세주소 건수가 0인 건물을 `상세주소 미부여`로 출력합니다.
   건물DB의 `상세주소부여여부` 값도 함께 출력하므로 교차 검증할 수 있습니다.

## 4. 결과 해석 시 주의

- 집합건축물(대장종류 `집합`)은 건축물대장의 동·호를 쓰므로 상세주소DB에 없을 수 있습니다.
  상세주소 부여 대상은 주로 **일반건축물**이므로 `대장종류` 열로 걸러 보세요.
- 건물명 키워드 판정은 참고용입니다. 정확한 결과를 얻으려면 건축물대장 표제부를 함께 넣으세요.
